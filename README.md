# Ozoo outreach agent

This agent follows up on leads after intake, by email and WhatsApp: the sequence, the reply
classifier, the WhatsApp chatbot, Cal.com bookings and the Microsoft Teams sales handoff.

- **Try it on your machine, with no accounts and no cost:** [docs/LOCAL_TESTING.md](docs/LOCAL_TESTING.md)
  (`scripts/local_setup`, then `scripts/run_local`).
- Settings: [.env.example](.env.example).
- Run the tests: `.venv/bin/pytest -q`.
